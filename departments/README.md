# 🦞 龙虾集团 - 组织架构

> 总裁：苏总 | 总经理：主Agent

## 部门列表

| 部门 | Agent ID | Emoji | 职位 | 职责 |
|------|----------|-------|------|------|
| 产品部 | `product` | 📊 | 产品经理 | 竞品分析、需求管理、PRD撰写、用户调研、产品规划 |
| 研发部 | `engineering` | 💻 | 技术总监 | 软件开发、网站维护、Bug修复、技术方案、代码审查 |
| 市场部 | `marketing` | 📣 | 市场总监 | 软文推广、公众号运营、小红书、社交媒体、品牌建设 |
| 运营部 | `operations` | 📈 | 运营总监 | 数据分析、用户运营、活动策划、SEO、增长黑客 |
| 销售部 | `sales` | 💰 | 销售总监 | 客户开发、邮件营销、商务对接、报价方案、CRM |
| 客服部 | `support` | 🎧 | 客服主管 | 消息回复、售后处理、FAQ维护、投诉处理、满意度 |
| 行政部 | `admin` | 📋 | 行政主管 | 日程管理、文件整理、会议纪要、任务跟踪、杂务 |

## 使用方式

通过 `sessions_spawn` 将任务分配给对应部门Agent：
- 指定 `agentId` 为部门英文名即可
- 部门Agent完成后会自动汇报结果

## 跨部门协作

需要多部门配合的任务由总经理（主Agent）协调分配。
