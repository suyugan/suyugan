# 龙虾集团 · 标准作业流程

## 任务处理流程

### Phase 1: 任务接收（指挥部）
1. 接收用户任务
2. 分析任务类型和复杂度
3. 拆解子任务，分配到对应部门
4. 设定优先级和预期时间

### Phase 2: 信息准备（情报部）
1. 搜集任务所需背景信息
2. 整理相关资料和数据
3. 事实核查，标注信息可信度
4. 输出情报简报给相关部门

### Phase 3: 方案设计（策略部）
1. 基于情报制定执行方案
2. 提供2-3个备选方案（如适用）
3. 评估风险和资源需求
4. 输出方案文档

### Phase 4: 执行产出（工程部/内容部）
1. 按方案执行具体任务
2. 工程部负责技术类任务
3. 内容部负责创意类任务
4. 实时更新进度

### Phase 5: 质量把关（质检部）
1. 审核产出物的准确性
2. 检查逻辑一致性
3. 优化表达和格式
4. 风险预警（发现问题立即反馈）

### Phase 6: 交付汇总（指挥部）
1. 汇总各部门产出
2. 最终审核和整合
3. 输出交付物给用户
4. 记录经验教训

## 协作规则
- 任何部门发现任务偏离目标，立即上报指挥部
- 跨部门协作时，由指挥部协调
- 质检部对所有产出有否决权
- 紧急任务可跳过Phase 2-3，但质检不可跳过
