**用户**: 苏煜淦
**目标**: 集成抖音/TikTok视频AI分析系统到OpenClaw

### 方案架构
```
Discord Bot
     ↓ 发视频链接
OpenClaw Gateway (Windows)
     ↓ 调用API
DS720 视频分析API
     ↓ 解析 + 下载 + AI分析
返回分析结果
     ↓
Discord Bot → 返回给用户
```

### 部署位置
- 推荐在 DS720 上部署
- 原因: NAS 24/7运行，局域网可访问，不占Windows资源

### DS720 部署步骤

1. **SSH连接到DS720**
2. **拉取Docker镜像**
   ```bash
   docker pull evil0ctal/douyin_tiktok_download_api
   ```

3. **启动容器**
   ```bash
   docker run -d \
     -p 18810:80 \
     --name douyin-api \
     evil0ctal/douyin_tiktok_download_api
   ```

4. **配置Cookie**
   - 从浏览器复制抖音Cookie
   - 更新容器内配置

5. **测试API**
   ```bash
   curl http://DS720的IP:18810/docs
   ```
