## 用户偏好：仿写脚本格式
苏总说「仿写」时，默认用以下POV短剧脚本格式：
- 开头：POV视角，电影画质，角色描述（外貌、穿着、特征）
- 分段时间戳：00:00-00:03, 00:03-00:08, 00:08-00:12, 00:12-00:15（共15秒）
- 每段包含：画面描述、音效、角色对话（含语气/表情描写）
- 风格：电影感、细腻的情绪描写、有张力的互动
- 参考模板见 Discord #漫剧短剧 频道的POV白衬衫脚本

## 视频分析系统完成部署 ✅

### 完整流程
1. **抖音API** (Docker端口18810) - 获取元数据+无水印下载链接
2. **ffmpeg** - 抽关键帧 + 提取音频
3. **Whisper** - 语音转文字(tiny模型)
4. **AI分析** - 逐帧分析画面内容
5. **小红书封面图** - HTML模板+浏览器截图生成

### 配置
- 下载目录: `D:\video-analysis\`
- API: `http://localhost:18810`
- 每个视频独立文件夹: `D:\video-analysis\{视频ID}\`
- 收到视频链接 → 必须spawn子代理处理

### 输出格式（苏总要求参照老林AI助手的格式）
1. 实时状态更新（下载/抽帧/转录/分析进度）
2. 完整报告：基本信息 → 画面内容 → 音频转录 → 总结
3. 小红书搬运素材：封面图建议+文案+发布建议
4. **生成小红书封面图**：HTML模板+browser截图+发送到频道

### 封面图方案
- 写HTML到 `D:\video-analysis\{视频ID}\cover.html`
- 用视频关键帧作为背景图
- 浏览器打开截图发送
- 模板已保存在TOOLS.md

## 注意事项
- PowerShell中curl是Invoke-WebRequest别名，用cmd /c或Invoke-RestMethod
- PowerShell的&&和||语法不同，用分号或管道
- Whisper运行需清除代理环境变量：NO_PROXY='*' ALL_PROXY='' HTTP_PROXY='' HTTPS_PROXY=''
- 浏览器服务偶尔超时，重启Gateway可解决
- 飞书API中文编码在PowerShell里会乱码，用UTF8编码
