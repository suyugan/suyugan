## 一、平台选择
- **优先用网页端**（jimeng.jianying.com），功能最全：智能多帧2.0、无限画布、多图层编辑、批量生成、Agent模式
- App端缺少高级功能（智能多帧、无限画布、批量生成）
- **2026.2.24即梦API接口对外公布**，届时可自建工作流/集成飞书多维表格

## 二、关键操作设置

### 参考图
- **必传**：人物头像参考图
- 变装类视频：额外传变装后的服装照片，**服装照片必须打马赛克/扣掉人脸**，否则AI会参考错误人脸
- 音频参考：传音频可匹配声线
- 视频参考：用于连续短剧（把第一段传入做第二段），但积分消耗翻倍
- **一般不传视频参考**，用强力精准提示词来约束连贯性和人脸一致性

### 模型选择
- **Seedance2.0 fast**：场景不复杂、分镜≤2个、人物不多时用，积分20分，速度快，大多数情况推荐
- **Seedance2.0**：复杂场景用

### 参考模式
- **无脑选"全能参考"**，这是Seedance的核心能力

## 三、提示词黄金法则

### 大原则
从清晰场景描述开始 → 指定镜头运动 → 定义光照和氛围 → 添加主体细节
- **控制在200字以内**效果最佳
- 提及物理交互（风吹头发、水花飞溅）可发挥物理模拟优势

### 六条法则
1. **精准不模糊**：避免"好看的画面""高级的光影"，直接用"暖色调柔光""金属细腻光泽"
2. **组合有逻辑**：按「镜头视角 + 光影色彩 + 美术材质 + 时间节奏 + 听觉音效 + 叙事结构」顺序
3. **适配场景**：探店=烟火气温馨感，千川=产品质感对比，门店引流=短平快福利
4. **控制长度**：单条提示词50-100字，避免信息过载
5. **添加优化词**：末尾加"即梦SeeDance适配，画面无模糊，无畸变，音画同步"
6. **5%微调法**：效果不佳只改1-2个关键词（光影/风格），不全部重写

## 四、万能公式

### 公式1：实体店同城探店
```
门店类型 + 市井风/对应风格 + 暖色调/对应色调 + 柔光/对应光质 + 探店动线结构 + [钩子类型] + 跟镜/摇镜 + 环境音 + 温馨/欢快BGM + 15-18秒竖版视频
```
示例：火锅店，市井烟火气，暖色调柔光，探店动线结构，结果前置钩子，跟镜拍摄，火锅沸腾音效+门店环境音，温馨背景音乐，15秒竖版视频

### 公式2：抖音千川付费素材
```
产品类型 + 核心材质 + 极简/ins风 + 冷/暖色调 + 硬/柔光 + 对比/卖点拆解结构 + [钩子类型] + 特写/环绕镜 + 产品音效/重音打击 + 无多余BGM + 15秒竖版视频
```
示例：清洁喷雾，液体丝滑流动，ins风，冷色调硬光，对比结构，痛点展示钩子，特写镜头，产品使用音效+重音打击，15秒竖版视频

### 公式3：门店自播流量视频
```
产品/福利 + 清新/明亮风格 + 自然光/柔光 + 快剪/无缝转场 + 福利钩子 + 特写/快速剪辑 + 欢快BGM + 10秒竖版视频
```
示例：奶茶店第二杯半价，清新ins风，自然光柔光，快速剪辑，福利钩子，饮品特写镜头，欢快背景音乐，10秒竖版视频

### 关键技巧
- 变装前后身体形态、距离、角度严格一致
- 服装参考图注明"肩宽略宽于参考图"避免穿帮
- 用物理交互（风吹）增加真实感
