一、OpenClaw 是什么？

简单来说，OpenClaw 是一个私人 AI 助手的中枢大脑。

它的核心是一个 Gateway（网关），
跑在你自己的电脑或服务器上，
同时连接多个聊天渠道：WhatsApp、Telegram、Discord、iMessage、Slack、微信（飞书）等等。
你在任何一个平台给它发消息，它就调用 AI 模型帮你处理。

几个核心特点：

🏠 自托管：数据在你自己的机器上，隐私你说了算
📱 多渠道：一个网关同时服务 WhatsApp、Telegram、Discord 等
🤖 Agent 原生：支持工具调用、会话管理、多代理路由
🔓 MIT 开源：完全免费，社区驱动
⚡ 5 分钟上手：只需要 Node.js 22+ 和一个 API Key

二、安装前准备

系统要求：
✅ macOS、Linux 或 Windows（推荐 WSL2）
✅ Node.js 22 或更高版本
✅ 一个 AI 模型的 API Key（推荐 Anthropic Claude）

检查 Node.js 版本：
打开终端，输入：

node --version

如果显示 v22.x.x 或更高，就没问题。
如果没装或版本太低，继续往下看。

安装 Node.js：

🍎 macOS：
用 Homebrew 安装最简单：

brew install node

🐧 Linux (Ubuntu/Debian)：

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

🪟 Windows：
用 winget 一条命令：

winget install OpenJS.NodeJS.LTS

也可以直接去 nodejs.org 下载安装包。

三、安装 OpenClaw

OpenClaw 提供了多种安装方式，
我按推荐程度排列，第一种最简单，适合大多数人。

方式一：一键安装脚本（推荐 ⭐）

🍎🐧 macOS / Linux / WSL2：

curl -fsSL https://openclaw.ai/install.sh | bash

🪟 Windows (PowerShell)：

iwr -useb https://openclaw.ai/install.ps1 | iex

这个脚本会自动检测 Node.js、安装 OpenClaw CLI，
并启动引导向导（Onboarding Wizard）。
整个过程一条命令搞定，非常省心。

方式二：npm 手动安装

如果你已经有 Node.js 22+，可以直接用 npm：

npm install -g openclaw@latest
openclaw onboard --install-daemon

方式三：从源码安装

适合开发者或想要最新功能的人：

git clone https://github.com/openclaw/openclaw.git
cd openclaw
pnpm install
pnpm ui:build
pnpm build
pnpm link --global

方式四：Docker 安装

如果你喜欢容器化部署：

git clone https://github.com/openclaw/openclaw.git
cd openclaw
./docker-setup.sh

脚本会自动构建镜像、运行引导向导、启动网关。

四、引导配置（Onboarding Wizard）

安装完成后，OpenClaw 会自动启动引导向导。
如果没有自动启动，手动运行：

openclaw onboard --install-daemon

向导会带你完成以下配置：

① 选择 AI 模型和认证方式
推荐使用 Anthropic API Key（Claude 系列模型）。
也支持 OpenAI、Gemini、xAI Grok、Moonshot 等。
向导会提示你输入 API Key。

② 工作区设置
默认在 ~/.openclaw/workspace。
这里存放 AI 的记忆、指令、技能文件等，
建议做成 Git 仓库备份。

③ 网关（Gateway）设置
端口默认 18789，绑定方式推荐 loopback（本地访问）。
会生成一个 Token 用于认证。

④ 聊天渠道配置
选择你要连接的平台：WhatsApp、Telegram、Discord 等。
WhatsApp 需要扫 QR 码，Telegram 只需 Bot Token。

⑤ 守护进程安装
让 OpenClaw 作为系统服务自动运行。
macOS 用 LaunchAgent，Linux 用 systemd。

五、启动和验证

配置完成后，检查网关状态：

openclaw gateway status

打开浏览器控制面板：

openclaw dashboard

会自动打开 http://127.0.0.1:18789/。
如果控制面板能正常加载，说明网关已经成功运行了！

你可以直接在浏览器里和 AI 对话，
不需要任何额外的渠道配置。

其他常用命令：

openclaw doctor        # 检查配置问题
openclaw status        # 查看网关状态
openclaw health        # 健康检查
openclaw logs --follow  # 查看实时日志

六、连接聊天渠道

OpenClaw 支持的渠道非常多，这里讲几个最常用的。

📱 WhatsApp

推荐用一个专门的手机号（第二张 SIM 卡或虚拟号）
作为 AI 助手的 WhatsApp 号码。

openclaw channels login

会弹出一个 QR 码，
用助手手机上的 WhatsApp 扫码即可。

然后在配置文件 ~/.openclaw/openclaw.json 中设置允许名单：

{
  "channels": {
    "whatsapp": {
      "allowFrom": ["+8613800138000"]
    }
  }
}

✈️ Telegram

Telegram 是最简单的渠道，
只需要一个 Bot Token：

1. 在 Telegram 找 @BotFather
2. 发 /newbot 创建机器人
3. 拿到 Bot Token
4. 在向导中填入，或手动写入配置

🎮 Discord

1. 去 Discord Developer Portal 创建 Application
2. 创建 Bot，获取 Token
3. 邀请 Bot 到你的服务器
4. 在向导中填入 Token

其他支持的渠道还有：
Slack、Signal、iMessage（BlueBubbles）、飞书、Google Chat、
Mattermost、IRC、Microsoft Teams、LINE、Matrix 等等。

七、核心配置详解

所有配置都在 ~/.openclaw/openclaw.json 文件里。
这里给一个完整的示例配置：

{
  "agent": {
    "model": "anthropic/claude-opus-4-6",
    "workspace": "~/.openclaw/workspace",
    "heartbeat": { "every": "30m" }
  },
  "channels": {
    "whatsapp": {
      "allowFrom": ["+8613800138000"]
    },
    "telegram": {
      "botToken": "YOUR_BOT_TOKEN"
    }
  },
  "session": {
    "scope": "per-sender",
    "resetTriggers": ["/new", "/reset"]
  }
}

关键配置项说明：

🧠 agent.model：选择默认 AI 模型
📁 agent.workspace：工作区路径
💓 agent.heartbeat：心跳间隔，AI 定时主动巡检
📱 channels：各渠道的配置
🔄 session.resetTriggers：发 /new 重置对话

八、工作区与记忆系统

OpenClaw 有一个很酷的设计：
AI 通过 Markdown 文件来记忆和学习。

工作区（默认 ~/.openclaw/workspace）里有几个核心文件：

📋 AGENTS.md — AI 的操作指南，定义行为规范
🧬 SOUL.md — AI 的人格和身份
👤 USER.md — 关于你（用户）的信息
🔧 TOOLS.md — 工具和设备的本地笔记
📝 memory/ — 每日记忆文件
🧠 MEMORY.md — 长期记忆精华

你可以编辑这些文件来调教你的 AI 助手，
让它更懂你的需求和习惯。

十、常见问题 FAQ

Q：openclaw 命令找不到？
A：多半是 PATH 问题。运行 npm prefix -g 查看全局安装路径，
确保该路径的 bin 目录在你的 PATH 里。

Q：npm install 报权限错误？
A：Linux 上常见。切换 npm 全局安装目录：

mkdir -p "$HOME/.npm-global"
npm config set prefix "$HOME/.npm-global"
export PATH="$HOME/.npm-global/bin:$PATH"

Q：WhatsApp 扫码总失败？
A：确保是在助手手机上扫码，不是你自己的手机。
建议用一个专门的号码。

Q：如何更新 OpenClaw？
A：推荐重新运行安装脚本（会自动升级）：

curl -fsSL https://openclaw.ai/install.sh | bash

或者手动更新：

npm i -g openclaw@latest
openclaw doctor
openclaw gateway restart

Q：如何卸载？
A：一条命令：

openclaw uninstall --all --yes

Q：在 Windows 上需要 WSL 吗？
A：强烈推荐使用 WSL2。
原生 Windows 也能跑，但 WSL2 兼容性更好。
