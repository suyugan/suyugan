# 小红书笔记搜索与选题分析

## 工作流程

### 第零步：创建输出目录

在当前工作目录下创建日期文件夹和子文件夹：

```bash
# 获取今日日期（YYMMDD 格式，如 260203）
DATE_DIR=$(date +%y%m%d)
OUTPUT_DIR="${DATE_DIR}/小红书分析选题分析"

# 创建目录（如已存在则跳过）
mkdir -p "$OUTPUT_DIR"
```

### 第一步：搜索笔记

运行搜索脚本获取笔记数据（输出到日期目录）：

```bash
DATE_DIR=$(date +%y%m%d)
OUTPUT_DIR="${DATE_DIR}/小红书分析选题分析"

python3 ~/.claude/skills/xhs-ana/scripts/xhs_search.py "关键词" \
  --pages 2 \
  --sort general \
  --detail \
  --output "${OUTPUT_DIR}/xhs_data.json"
```

**参数说明：**
- `--pages`：获取页数（默认 2，每页约 20 条）
- `--sort`：排序方式
  - `general`：综合排序（默认）
  - `popularity_descending`：按热度
  - `time_descending`：按时间
- `--type`：笔记类型（all/image/video）
- `--time`：发布时间（不限/一天内/一周内/一月内/三月内）
- `--range`：点赞范围（不限/0-1000/1000-5000/5000-1w/1w+）
- `--detail`：获取笔记正文详情
- `--output`：输出 JSON 文件路径

### 第二步：生成搜索结果 Markdown

读取 JSON 数据，在日期目录下生成 `xhs_搜索_{关键词}_{日期}.md`：

```markdown
# 小红书笔记搜索：{关键词}

> 搜索时间：YYYY-MM-DD HH:mm
> 笔记数量：N 条
> 排序方式：综合/热度/最新

## 数据概览

| 指标 | 数值 |
|------|------|
| 总点赞 | X |
| 总收藏 | X |
| 总评论 | X |
| 平均互动率 | X% |
| 图文/视频 | X/Y |

## 笔记列表

### 1. {标题}

- **作者**：{昵称}
- **类型**：图文/视频
- **数据**：{点赞} 赞 | {收藏} 藏 | {评论} 评 | 互动率 {X}%
- **链接**：[查看原文]({URL})

**正文摘要**：
> {前 300 字}...

---
```

### 第三步：选题分析

基于搜索数据进行多维度分析，在日期目录下生成 `xhs_分析_{关键词}_{日期}.md`。

分析维度参考 `references/analysis_framework.md`：

1. **内容分类**：将笔记归类（教程/种草/经验/资讯/故事/清单）
2. **标题分析**：高频词、标题模式、情感词
3. **互动数据**：点赞/收藏/评论分布、图文vs视频对比
4. **爆款拆解**：Top 5 笔记深度分析
5. **选题建议**：热门方向、标题写法、差异化角度

## 输出文件

所有文件保存在当前工作目录下的日期子文件夹中：

```
./
└── YYMMDD/                               # 日期文件夹（如 260203）
    └── 小红书分析选题分析/
        ├── xhs_data.json                 # 原始 JSON 数据
        ├── xhs_搜索_{关键词}_{日期}.md   # 搜索结果文档
        └── xhs_分析_{关键词}_{日期}.md   # 选题分析报告
```

**说明：**
- 日期文件夹格式为 `YYMMDD`（如 2026年2月3日 → `260203`）
- 如果日期文件夹或子文件夹不存在，会自动创建
- 如果已存在，新文件会追加到该目录下

## 使用示例

用户："帮我搜索小红书上关于 AI 绘画的笔记并分析选题"

执行流程：
1. 创建目录 `mkdir -p 260203/小红书分析选题分析`
2. 运行 `xhs_search.py "AI绘画" --pages 3 --detail --output 260203/小红书分析选题分析/xhs_data.json`
3. 读取 JSON，生成 `260203/小红书分析选题分析/xhs_搜索_AI绘画_2026-02-03.md`
4. 分析数据，生成 `260203/小红书分析选题分析/xhs_分析_AI绘画_2026-02-03.md`

## 注意事项

- 搜索脚本依赖 `requests` 库，首次使用需确认已安装
- `--detail` 参数会调用额外 API 获取正文，耗时较长
- 分析报告中的"爆款原因"需结合正文内容深度分析
