# 演示文稿分析框架

用于创建有效幻灯片的深度内容分析。

## 1. 信息层次

在设计幻灯片之前识别核心信息结构。

### 核心信息（一句话）
- 最重要的要点是什么？
- 如果观众只记住一件事，应该是什么？
- 能用 ≤15 个词表达吗？

### 支撑要点（最多 3-5 个）
- 什么证据支持核心信息？
- 必须涵盖哪些子话题？
- 按观众相关性优先排序，而非源材料顺序

### 行动号召
- 观看后观众应该做什么？
- 是否清晰、具体、可实现？
- 出现在哪里（幻灯片位置）？

## 2. 受众决策矩阵

| 问题 | 分析 |
|----------|----------|
| 主要受众是谁？ | [角色、专业水平、与话题的关系] |
| 他们目前的认知是什么？ | [现有知识、假设、偏见] |
| 我们希望他们做出什么决定？ | [具体行动或结论] |
| 存在什么障碍？ | [反对意见、顾虑、缺失信息] |
| 什么证据能说服他们？ | [数据类型、可信度来源、情感钩子] |

### 受众适配

| 受众类型 | 内容重点 | 视觉处理 |
|---------------|---------------|------------------|
| 高管 | 成果、投资回报、战略影响 | 高层次、简洁、数据亮点 |
| 技术人员 | 架构、实施、规格 | 详细图表、代码、示意图 |
| 通用 | 收益、故事、关联性 | 视觉隐喻、简单图表 |
| 投资者 | 市场规模、牵引力、团队 | 增长图表、里程碑、对比 |
| 学习者 | 分步骤、示例、练习 | 渐进揭示、练习题 |

## 3. 视觉机会图

识别哪些内容适合可视化。

### 内容到视觉映射

| 内容类型 | 视觉处理 | 示例 |
|--------------|------------------|---------|
| 比较 | 并排、前后对比 | 功能对比表 |
| 流程 | 流程图、编号步骤 | 工作流程插图 |
| 层级 | 组织图、金字塔、树形图 | 组织结构 |
| 时间线 | 水平/垂直时间线 | 项目里程碑 |
| 统计 | 图表、突出数字 | 带上下文的关键指标 |
| 概念 | 图标、隐喻、插图 | 抽象概念可视化 |
| 关系 | 维恩图、网络图 | 生态系统或依赖关系 |
| 列表 | 结构化网格、图标行 | 带图标的功能要点 |

### 视觉优先级

对每个内容评分：
- **必须可视化**：复杂数据、关键差异点、难忘时刻
- **应该可视化**：支撑证据、次要观点
- **仅文本**：简单陈述、过渡、次要细节

## 4. 演示流程

为影响力和记忆度构建结构。

### 开场（前 2-3 张幻灯片）

| 元素 | 目的 |
|---------|---------|
| 钩子 | 抓住注意力（令人惊讶的统计、问题、故事） |
| 背景 | 为什么现在这很重要 |
| 预览 | 观众将学到/获得什么 |

### 中间（内容幻灯片）

| 模式 | 何时使用 |
|---------|-------------|
| 问题 → 解决方案 | 介绍新产品/想法 |
| 情境 → 复杂性 → 解决 | 复杂商业案例 |
| 是什么 → 为什么 → 怎么做 | 教育内容 |
| 过去 → 现在 → 未来 | 转型故事 |
| 论点 → 证据 → 启示 | 数据驱动论证 |

### 结尾（最后 2-3 张幻灯片）

| 元素 | 目的 |
|---------|---------|
| 综合 | 回扣核心信息 |
| 行动号召 | 清晰的下一步 |
| 难忘收尾 | 引人共鸣的引言、图像或陈述 |

### 过渡

- 每张幻灯片应回答："接下来是什么？"
- 在各部分之间使用叙事连接词
- 构建逻辑递进，而非话题跳跃

## 5. 内容适配

决定保留、转换或省略什么。

### 保留（高价值）
- 核心论点和证据
- 独特见解或数据
- 与受众相关的示例
- 难忘的引言或统计

### 简化（中等价值）
- 技术细节 → 视觉摘要
- 长篇解释 → 要点层级
- 多个示例 → 最佳 1-2 个示例
- 背景上下文 → 简要框架

### 可视化（转换）
- 数据表 → 图表或突出数字
- 流程描述 → 流程图
- 文本中的比较 → 并排视觉
- 抽象概念 → 具体隐喻

### 省略（低价值）
- 题外信息
- 冗余示例
- 过多的免责声明
- 观众已知的背景

## 6. 分析检查清单

创建大纲前确认：

### 信息清晰度
- [ ] 核心信息用一句话表述
- [ ] 识别了 3-5 个支撑要点
- [ ] 定义了行动号召

### 受众契合度
- [ ] 识别了主要受众
- [ ] 映射了现有认知
- [ ] 明确了期望决定
- [ ] 证据匹配受众需求

### 视觉规划
- [ ] 识别了关键可视化
- [ ] 选择了图表/图示类型
- [ ] 分配了视觉优先级

### 流程设计
- [ ] 定义了开场钩子
- [ ] 选择了中间模式
- [ ] 规划了结尾方式
- [ ] 考虑了过渡

### 内容决策
- [ ] 应用了保留/简化/可视化/省略
- [ ] 完全处理了源材料
- [ ] 没有遗漏重要内容
