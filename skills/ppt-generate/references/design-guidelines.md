# 设计指南

幻灯片的详细设计原则。

## 受众指南

设计决策根据目标受众调整。使用 `--audience` 设置。

| 受众 | 内容密度 | 视觉风格 | 术语 | 幻灯片数 |
|----------|-----------------|--------------|-------------|--------|
| `beginners` | 低 | 友好、插图式 | 通俗语言 | 8-15 |
| `intermediate` | 中 | 平衡、结构化 | 可用一些术语 | 10-20 |
| `experts` | 高 | 数据丰富、精确 | 技术术语 | 12-25 |
| `executives` | 低-中 | 干净、有冲击力 | 商业语言 | 8-12 |
| `general` | 中 | 易于理解、引人入胜 | 最少术语 | 10-18 |

### 受众 → 密度映射

基于受众的推荐密度维度：

| 受众 | 推荐密度 | 理由 |
|----------|-------------------|-----------|
| `executives` | minimal | 每张幻灯片一个洞察，尊重时间 |
| `beginners` | minimal → balanced | 单一概念，逐步建立理解 |
| `general` | balanced | 易于理解但信息丰富 |
| `intermediate` | balanced | 标准信息密度 |
| `experts` | balanced → dense | 能处理更多每张幻灯片的数据 |

**自动密度选择**：
- 如果 `--audience executives` → 默认 `minimal` 密度
- 如果 `--audience beginners` → 默认 `minimal` 或 `balanced`
- 如果 `--audience experts` → 允许 `dense` 密度
- 否则 → 默认 `balanced`

### 受众特定原则

**初学者**：
- 每张幻灯片一个概念
- 视觉隐喻优于抽象图表
- 逐步递进
- 慷慨的留白

**专家**：
- 每张幻灯片可接受多个数据点
- 带精确标签的技术图表
- 假设有领域知识
- 密集但有组织的信息

**高管**：
- 以洞察而非数据开头
- 每张幻灯片都有"那又怎样？"
- 支持决策的内容
- 结论先行（BLUF）

## 视觉层次原则

| 原则 | 描述 |
|-----------|-------------|
| 焦点 | 每张幻灯片一个主导元素首先吸引注意力 |
| 三分法 | 关键元素放置在网格交叉点 |
| Z 型模式 | 引导眼睛：左上 → 右上 → 左下 → 右下 |
| 尺寸对比 | 标题比正文大 2-3 倍 |
| 呼吸空间 | 距所有边缘最少 10% 边距 |

## 内容密度

参见 `references/dimensions/density.md` 了解完整密度维度规格。

| 级别 | 描述 | 使用场景 |
|-------|-------------|----------|
| 高 | 多个数据点、详细图表、密集文本 | 专家受众、技术评审 |
| 中 | 要点带支撑细节 | 通用商务、混合受众 |
| 低 | 一个主要观点、大视觉、最少文本 | 初学者、主题演讲、情感冲击 |

**高密度原则**（麦肯锡风格）：
- 每个元素都要赢得它的位置
- 数据比装饰更有说服力
- 注释解释洞察，而非描述数据
- 留白是战略性的，而非填充物

**按幻灯片类型的密度**：
| 幻灯片类型 | 推荐密度 |
|------------|-------------------|
| 封面/标题 | minimal |
| 议程/概览 | balanced |
| 内容/分析 | balanced 或 dense |
| 数据/指标 | dense |
| 引言/冲击 | minimal |
| 摘要/要点 | balanced |

## 颜色选择

参见 `references/dimensions/mood.md` 了解完整色调维度规格。

**内容优先方法**：
1. 分析内容话题、情绪和行业
2. 考虑目标受众期望
3. 匹配调色板与主题
4. 确保足够的对比度以保证可读性

**快速调色板指南**：
| 内容类型 | 推荐色调 |
|--------------|-----------------|
| 技术/架构 | cool |
| 教育/友好 | warm |
| 企业/专业 | professional |
| 创意/艺术 | vibrant |
| 科学/医学 | cool 或 neutral |
| 娱乐/游戏 | dark 或 vibrant |

## 排版原则

参见 `references/dimensions/typography.md` 了解完整排版维度规格。

| 元素 | 处理 |
|---------|-----------|
| 标题 | 粗体，正文 2-3 倍大小，叙事风格 |
| 正文 | 常规字重，可读大小 |
| 说明文字 | 更小，更轻字重 |
| 数据标签 | 技术内容使用等宽字体 |
| 强调 | 使用粗体或颜色，不使用下划线 |

## 字体推荐

**英文字体**：
| 字体 | 风格 | 最适用于 |
|------|-------|----------|
| Liter | 无衬线、几何 | 现代、干净、技术 |
| HedvigLettersSans | 无衬线、独特 | 品牌导向、创意 |
| Oranienbaum | 高对比衬线 | 优雅、古典 |
| SortsMillGoudy | 古典衬线 | 传统、易读 |
| Coda | 圆形无衬线 | 友好、亲切 |

**中文字体**：
| 字体 | 风格 | 最适用于 |
|------|-------|----------|
| MiSans | 现代无衬线 | 干净、通用、屏幕优化 |
| Noto Sans SC | 中性无衬线 | 标准、多语言 |
| 思源宋体 | 精致宋体 | 优雅、编辑 |
| 阿里妈妈数黑体 | 几何无衬线 | 商业、结构化 |
| LXGW Bright | 宋楷混合 | 温暖、易读 |

**多语言配对**：
| 用途 | 英文 | 中文 |
|----------|---------|---------|
| 技术 | Liter | MiSans |
| 编辑 | Oranienbaum | 思源宋体 |
| 友好 | Coda | LXGW Bright |

## 视觉元素参考

参见 `references/dimensions/texture.md` 了解完整纹理维度规格。

### 背景处理

| 处理 | 描述 | 最适用于 |
|-----------|-------------|----------|
| 纯色 | 单一背景颜色 | 干净、极简 |
| 分割背景 | 双色，对角或垂直 | 对比、分区 |
| 渐变 | 细微的垂直或对角渐变 | 现代、动感 |
| 纹理 | 图案或纹理叠加 | 个性、风格 |

### 排版处理

| 处理 | 描述 | 最适用于 |
|-----------|-------------|----------|
| 尺寸对比 | 标题与正文 3-4 倍差异 | 冲击力、层次 |
| 全大写标题 | 带字母间距的大写 | 权威、结构 |
| 等宽数据 | 数字/代码使用等宽 | 技术、精确 |
| 手绘 | 有机、不完美的字形 | 友好、亲切 |

### 几何装饰

| 元素 | 描述 | 最适用于 |
|---------|-------------|----------|
| 对角分隔 | 倾斜的区域分隔线 | 能量、运动 |
| 角落方括号 | L 形框架 | 聚焦、框定 |
| 圆形/六边形 | 图像的形状框架 | 现代、科技 |
| 下划线装饰 | 标题下的粗线 | 强调、层次 |

## 一致性要求

| 元素 | 指南 |
|---------|-----------|
| 间距 | 全程一致的边距和内边距 |
| 颜色 | 每张幻灯片最多 3-4 种颜色，调色板全程一致 |
| 排版 | 相同内容类型使用相同字体族和大小 |
| 视觉语言 | 重复图案、形状和处理方式 |

## 维度组合指南

组合维度时考虑兼容性：

| 受众 | 推荐维度 |
|----------|----------------------|
| 高管 | clean + neutral + geometric + minimal |
| 初学者 | organic + warm + humanist + minimal |
| 通用 | 任何纹理 + 任何色调 + humanist/geometric + balanced |
| 专家 | grid/clean + cool + technical + balanced/dense |

| 内容类型 | 推荐维度 |
|--------------|----------------------|
| 教程 | organic + warm + handwritten + balanced |
| 技术 | grid + cool + technical + balanced |
| 商务 | clean + professional + geometric + balanced |
| 创意 | organic + vibrant + humanist + balanced |
| 数据密集 | clean + cool + technical + dense |
