# 密度维度

每张幻灯片的信息密度。

## 选项

| 选项 | 每张幻灯片内容 | 留白 | 最适用于 |
|--------|---------------|------------|----------|
| `minimal` | 一个焦点 | 最大 | 高管简报、主题演讲、情感冲击 |
| `balanced` | 2-3 个要点 | 标准 | 通用演示、混合受众 |
| `dense` | 多个数据点 | 紧凑 | 数据密集、技术评审、详细分析 |

## 渲染指南

### minimal

- 每张幻灯片一个主要观点
- 大视觉占主导
- 最少文本（标题 + 最多 1-2 行）
- 慷慨的边距（距边缘 15%+）
- 元素之间最大呼吸空间
- 让单一元素承载全部权重

**原则**：
- "一张幻灯片，一个信息"
- 视觉 > 文本
- 空白是有意的
- 每个元素必须赢得它的位置

### balanced

- 每张幻灯片 2-3 个要点
- 标准边距（距边缘 10%）
- 平衡的文本/视觉比例
- 清晰的层次结构带支撑细节
- 舒适的阅读体验

**原则**：
- 主要观点 + 支撑上下文
- 视觉补充文本
- 结构化但不拥挤
- 适合多样化受众

### dense

- 可接受多个数据点
- 紧凑边距（距边缘 5-8%）
- 信息丰富的布局
- 图表、表格、详细注释
- 假设参与度高、专注的受众

**原则**：
- 数据比装饰更有说服力
- 注释解释洞察
- 留白是战略性的
- 每个像素都服务于目的

## 受众 → 密度映射

| 受众 | 推荐密度 |
|----------|-------------------|
| 高管 | minimal |
| 初学者 | minimal 到 balanced |
| 通用 | balanced |
| 中级 | balanced |
| 专家 | balanced 到 dense |

## 幻灯片类型 → 密度指南

| 幻灯片类型 | 推荐密度 |
|------------|-------------------|
| 封面/标题 | minimal |
| 章节分隔 | minimal |
| 引言/冲击 | minimal |
| 议程/概览 | balanced |
| 内容/分析 | balanced 或 dense |
| 摘要/要点 | balanced |
| 数据/指标 | dense |

## 每种密度的内容指南

### minimal

| 元素 | 指南 |
|---------|-----------|
| 标题 | 大号（相当于 40-60pt） |
| 正文 | 最少或没有 |
| 要点 | 最多 0-2 个 |
| 视觉元素 | 1 个主导元素 |
| 图表/数据 | 仅 1 个关键统计 |

### balanced

| 元素 | 指南 |
|---------|-----------|
| 标题 | 中大号（相当于 32-48pt） |
| 正文 | 2-4 行 |
| 要点 | 2-4 个 |
| 视觉元素 | 1-2 个元素 |
| 图表/数据 | 简单图表可以 |

### dense

| 元素 | 指南 |
|---------|-----------|
| 标题 | 中等（相当于 24-36pt） |
| 正文 | 多段落可以 |
| 要点 | 4-6+ 个 |
| 视觉元素 | 多个允许 |
| 图表/数据 | 复杂图表、表格可以 |

## 组合注意事项

| 密度 | 最佳搭配 | 避免搭配 |
|---------|-----------------|------------|
| minimal | neutral 色调、geometric 排版 | 密集数据内容 |
| balanced | 任何色调/排版 | 极端（太稀疏或太拥挤） |
| dense | cool 色调、technical 排版 | handwritten 排版、organic 纹理 |
