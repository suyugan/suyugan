# 大纲模板

带样式说明的幻灯片大纲标准结构。

## 大纲格式

```markdown
# 幻灯片大纲

**主题**：[主题描述]
**样式**：[预设名称或"custom"]
**维度**：[纹理] + [色调] + [排版] + [密度]
**受众**：[目标受众]
**语言**：[输出语言]
**幻灯片数**：N 张
**生成时间**：YYYY-MM-DD HH:mm

---

<STYLE_INSTRUCTIONS>
设计美学：[2-3 句描述，结合维度特征]

背景：
  纹理：[来自纹理维度]
  基础颜色：[来自色调维度调色板]

排版：
  标题：[来自排版维度——描述视觉外观]
  正文：[来自排版维度——描述视觉外观]

调色板：
  主要文本：[名称]（[十六进制]）- [用途]
  背景：[名称]（[十六进制]）- [用途]
  强调色 1：[名称]（[十六进制]）- [用途]
  强调色 2：[名称]（[十六进制]）- [用途]

视觉元素：
  - [来自纹理 + 色调组合的元素 1]
  - [带渲染指导的元素 2]
  - ...

密度指南：
  - 每张幻灯片内容：[来自密度维度]
  - 留白：[来自密度维度]

样式规则：
  应做：[来自维度组合的指南]
  不应做：[来自维度组合的反模式]
</STYLE_INSTRUCTIONS>

---

[幻灯片条目跟随...]
```

## 从维度构建 STYLE_INSTRUCTIONS

使用自定义维度或预设时，通过组合以下内容构建 STYLE_INSTRUCTIONS：

### 1. 设计美学

将所有四个维度的特征组合成 2-3 句：

| 纹理 | 贡献 |
|---------|--------------|
| clean | "干净、数字精度，边缘锐利" |
| grid | "技术网格叠加，工程精度" |
| organic | "手绘感，柔和纹理" |
| pixel | "粗块像素美学，8 位魅力" |
| paper | "做旧纸张纹理，复古特色" |

| 色调 | 贡献 |
|------|--------------|
| professional | "专业海军蓝和金色调色板" |
| warm | "暖大地色调，营造亲切氛围" |
| cool | "冷分析蓝和灰" |
| vibrant | "大胆、高饱和度色彩，充满活力" |
| dark | "深沉电影感背景，发光强调" |
| neutral | "极简灰度，精致感" |

### 2. 背景

来自 `references/dimensions/texture.md`：
- 纹理描述
- 来自色调调色板的基础颜色

### 3. 排版

来自 `references/dimensions/typography.md`：
- 标题视觉描述（不是字体名称）
- 正文视觉描述（不是字体名称）

**重要**：为图片生成描述外观："粗体几何无衬线，O 形状完美圆形"而不是"Inter 字体"。

### 4. 调色板

来自 `references/dimensions/mood.md`：
- 复制所选色调的调色板规格
- 包含十六进制代码和用途说明

### 5. 视觉元素

组合纹理和色调特征：

| 组合 | 视觉元素 |
|-------------|-----------------|
| clean + professional | 干净图表、轮廓图标、结构化网格 |
| grid + cool | 技术示意图、尺寸线、蓝图 |
| organic + warm | 手绘图标、笔刷笔触、涂鸦 |
| pixel + vibrant | 像素艺术图标、复古游戏元素 |
| paper + warm | 复古印章、做旧元素、棕褐色叠加 |

### 6. 密度指南

来自 `references/dimensions/density.md`：
- 每张幻灯片内容限制
- 留白要求
- 元素数量指南

### 7. 样式规则

组合维度特定规则：

**按纹理的应做规则**：
- clean：保持锐利边缘，使用网格对齐
- grid：显示精确测量，使用技术图表
- organic：允许不完美，用微妙重叠分层
- pixel：保持锯齿边缘，使用粗块元素
- paper：添加微妙做旧效果，使用暖色调

**按纹理的不应做规则**：
- clean：不使用手绘元素
- grid：不使用有机曲线
- organic：不使用完美几何
- pixel：不平滑边缘
- paper：不使用明亮的数字颜色

## 封面幻灯片模板

```markdown
## 第 1 张，共 N 张

**类型**：封面
**文件名**：01-slide-cover.png

// 叙事目标
[此幻灯片在故事弧中实现的目标]

// 关键内容
标题：[主标题]
副标题：[支持性标语]

// 视觉
[详细视觉描述——具体元素、构图、情绪]

// 布局
布局：[可选：布局库中的布局名称，例如 title-hero]
[构图、层次、空间安排]
```

```markdown

**类型**：内容

// 叙事目标

正文：
- [带具体细节的要点 1]

- [带具体细节的要点 3]

// 视觉
[详细视觉描述]

// 布局
布局：[可选：布局库中的布局名称]
[构图、层次、空间安排]
```

## 封底幻灯片模板

```markdown
## 第 N 张，共 N 张

**类型**：封底
**文件名**：{NN}-slide-back-cover.png

// 叙事目标
[有意义的收尾——不只是"谢谢"]

// 关键内容
标题：[难忘的结束语或行动号召]

// 布局

```

## STYLE_INSTRUCTIONS 块

`<STYLE_INSTRUCTIONS>` 块是此大纲中样式信息的**唯一真实来源**。

| 部分 | 内容 | 来源 |
|---------|---------|--------|
| 设计美学 | 整体视觉方向 | 所有维度组合 |
| 背景 | 基础颜色和纹理细节 | 纹理 + 色调维度 |
| 排版 | 字体描述（视觉，非名称） | 排版维度 |
| 调色板 | 带十六进制代码和用途的命名颜色 | 色调维度 |
| 视觉元素 | 带渲染说明的图形元素 | 纹理 + 色调维度 |
| 密度指南 | 内容限制和留白 | 密度维度 |
| 样式规则 | 应做/不应做指南 | 维度组合 |

**重要**：
- 排版描述必须描述视觉外观（例如"圆润无衬线"、"粗体几何"），因为图片生成器无法使用字体名称
- 提示词应从此大纲提取 STYLE_INSTRUCTIONS，不要重新读取样式文件

## 章节分隔符

在以下之间使用 `---`（水平线）：
- 头部元数据和 STYLE_INSTRUCTIONS
- STYLE_INSTRUCTIONS 和第一张幻灯片
- 每个幻灯片条目

## 幻灯片编号

- 封面始终是第 1 张
- 内容幻灯片使用顺序编号
- 封底始终是最后一张（第 N 张）
- 文件名前缀匹配幻灯片位置：`01-`、`02-` 等

## 文件名 Slug

从幻灯片内容生成有意义的 slug：

| 幻灯片类型 | Slug 模式 | 示例 |
|------------|--------------|---------|
| 封面 | `cover` | `01-slide-cover.png` |
| 内容 | `{topic-slug}` | `02-slide-problem-statement.png` |
| 封底 | `back-cover` | `10-slide-back-cover.png` |

Slug 规则：
- kebab-case（小写、连字符）
- 从标题或主要话题派生
- 最多 30 个字符
- 在幻灯片内唯一
