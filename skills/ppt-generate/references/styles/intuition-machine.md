# intuition-machine

技术简报信息图风格，做旧纸张纹理和双语解释文本框

## 设计美学

学术/技术简报演示风格，而非艺术性 3D 渲染。干净的 2D 或等轴测技术插图，配多个包含文章内容的解释性文本框。分割布局，视觉在左/中，文本在右/下。信息密集但有组织，清晰的视觉层次。复古蓝图美学与现代清晰度结合。

## 背景

- 颜色：做旧奶油色（#F5F0E6）
- 纹理：细微纸张纹理，轻微折痕，温暖怀旧感，让人联想到复古技术印刷品

## 排版

### 主字体（标题）

粗体展示字体，深酒红色，主标题全大写带方括号。下方较小尺寸的英文副标题。技术、权威的存在感，带复古特质。

### 副字体（标签）

双语标注标签使用干净无衬线。格式："ENGLISH TERM 中文翻译"。与背景高对比。

### 正文字体

文本框内容使用干净几何无衬线。小尺寸可读。全程字重一致。

## 视觉元素

- 等轴测 3D 技术插图或扁平 2D 图表（根据概念选择）
- 每张幻灯片 3-5 个带标签内容的解释性文本框
- 双语标注标签指向关键部分
- 与话题相关的淡化主题背景图案（电路、齿轮、流程图）
- 所有元素干净的黑色轮廓
- 分割或三联画布局
- 底部"关键引言："框，包含核心洞察
- 角落不加标题块、印章或水印

## 样式规则

### 应做

- 包含 3-5 个文本框，内容来自源材料
- 关键元素使用双语标签（英文 + 中文）
- 添加与话题相关的淡化主题背景图案
- 全程保持做旧纸张纹理
- 使用分割布局创建清晰的视觉层次

### 不应做

- 创建逼真渲染或艺术性 3D 场景
- 让幻灯片没有解释性文本内容
- 在角落添加标题块或印章
- 使用渐变或光泽效果
- 添加幻灯片编号、页脚或标志

## 最适用于

技术讲解、概念分解、学术演示、知识文档、研究摘要、深度教育内容、双语受众
