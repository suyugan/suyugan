# 小红书选题分析框架

## 分析维度

### 1. 内容分类归纳
将笔记按主题/子领域分类：
- 教程类（How-to）
- 种草类（推荐/测评）
- 经验分享类
- 资讯类
- 故事类
- 清单类

### 2. 标题特征分析
- 标题长度分布
- 高频关键词
- 标题结构模式（数字型、疑问型、对比型等）
- 情感词使用
- emoji 使用情况

### 3. 互动数据分析
- 点赞/收藏/评论分布
- 互动率计算：(点赞+收藏+评论)/预估曝光
- 高互动笔记特征提取
- 图文 vs 视频表现对比

### 4. 爆款拆解
对互动量 Top 5 笔记进行深度分析：
- 标题吸引力要素
- 内容结构
- 视觉呈现
- 互动引导技巧
- 可复制的写作方法

### 5. 选题建议
基于分析结果输出：
- 热门话题方向
- 内容形式建议
- 标题写作建议
- 差异化角度
