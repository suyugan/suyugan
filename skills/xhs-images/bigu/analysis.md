# 辟谷主题 - 深度分析

## 内容类型
**干货科普 + 种草分享**（健康/养生类）

## 主题概述
辟谷是中国传统养生方法，近年在健康圈重新流行。内容覆盖：辟谷定义、好处、准备工作、注意事项、复食方法、常见误区。

## 目标用户
- 25-45岁女性，关注健康/养生/减脂
- 小红书活跃用户，喜欢收藏干货
- 对传统养生有兴趣但缺乏系统了解
- 有减肥/排毒/身体调理需求

## 钩子分析
- "辟谷≠绝食！90%的人都搞错了"（纠错型，高点击）
- 养生话题自带流量，配合"瘦了X斤"等数据更有说服力
- 适合做系列图文，收藏价值高

## 互动潜力
- **收藏**: ⭐⭐⭐⭐⭐（干货型，极高收藏率）
- **分享**: ⭐⭐⭐⭐（实用性强，转发给朋友/家人）
- **评论**: ⭐⭐⭐⭐（容易引发讨论：你试过吗？）

## 视觉机会
- warm风格 → 温暖亲切，适合养生话题
- 可用食物、自然元素、身体图标等视觉符号
- 流程图适合展示辟谷阶段
- 对比图适合展示误区 vs 正确做法

## 滑动流设计（7张）
1. 封面：钩子标题，吸引点击
2. 辟谷是什么：科普定义
3. 辟谷的好处：列举益处
4. 辟谷前准备：准备清单
5. 辟谷中注意事项：关键提醒
6. 辟谷后复食：流程指南
7. 常见误区 + CTA：纠错 + 互动引导

## 风格决策
- **风格**: warm（温暖亲切，养生话题最佳匹配）
- **布局**: balanced + flow 混合
- **策略**: A（故事驱动）+ B（信息密集）混合
- **图片数量**: 7张
