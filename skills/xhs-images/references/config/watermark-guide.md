# 水印指南

## 位置图示

```
┌─────────────────────────────┐
│                  [右上角]   │
│                             │
│                             │
│         图片内容            │
│                             │
│                             │
│[左下角]  [底部居中]  [右下角]│
└─────────────────────────────┘
```

## 位置建议

| 位置 | 适用场景 | 避免情况 |
|----------|----------|------------|
| `bottom-right` | 默认选择，最常见 | 右下角有重要信息 |
| `bottom-left` | 布局偏右的设计 | 左下角有重要信息 |
| `bottom-center` | 居中设计 | 底部文字过多 |
| `top-right` | 内容偏底部 | 标题/头部在右上角 |

## 内容格式

| 格式 | 示例 | 风格 |
|--------|---------|-------|
| 账号 | `@用户名` | 小红书最常见 |
| 文字 | `我的品牌` | 简单品牌标识 |
| 中文 | `小红书:用户名` | 平台特定 |
| 网址 | `myblog.com` | 跨平台使用 |

## 最佳实践

1. **一致性**：系列所有图片使用相同水印
2. **可读性**：确保在浅色/深色区域都清晰可见
3. **尺寸**：保持微妙 - 不应干扰主要内容

## 提示词整合

启用水印时，添加到图片生成提示词：

```
在 [位置] 添加微妙的水印 "[内容]"。
水印应清晰可辨但不干扰主要内容。
```

## 常见问题

| 问题 | 解决方案 |
|-------|----------|
| 水印不可见 | 调整位置或检查对比度 |
| 水印太显眼 | 更换位置或减小尺寸 |
| 水印遮挡内容 | 更换位置 |
| 各图水印不一致 | 使用会话 ID 保持一致性 |
