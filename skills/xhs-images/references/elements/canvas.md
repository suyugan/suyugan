# 画布与布局

小红书信息图的核心画布规格和布局网格。

## 宽高比

| 名称 | 比例 | 像素 | 说明 |
|------|-------|--------|------|
| portrait-3-4 | 3:4 | 1242×1660 | 小红书流量最高（推荐） |
| square | 1:1 | 1242×1242 | 次推荐 |
| portrait-2-3 | 2:3 | 1242×1863 | 更高的竖版格式 |

**默认**：portrait-3-4 以获得最大互动。

## 安全区域

避免在以下区域放置关键内容：

| 区域 | 位置 | 原因 |
|------|----------|--------|
| bottom-overlay | 底部 10% | 移动端标题栏遮挡 |
| top-right | 右上角 | 点赞/分享按钮遮挡 |
| bottom-right | 右下角 | 水印位置 |

```
┌─────────────────────────────┐
│                 [点赞/分享] │  ← 右上角：避免
│                             │

│                             │
│                             │
│  [标题栏遮挡区域]           │  ← 底部10%：避免关键信息
└─────────────────────────────┘
```

## 网格布局

### 基于密度的布局

| 布局 | 信息密度 | 留白 | 信息点/张 | 适用场景 |
|--------|--------------|------------|--------------|----------|
| sparse | 低 | 60-70% | 1-2 | 封面、金句、冲击语句 |
| balanced | 中 | 40-50% | 3-4 | 标准内容、教程 |
| dense | 高 | 20-30% | 5-8 | 知识卡片、速查表 |

### 基于结构的布局

| 布局 | 结构 | 项目数 | 适用场景 |
|--------|-----------|-------|----------|
| list | 垂直列举 | 4-7 | 排名、清单、步骤指南 |
| comparison | 左右对比 | 2个区块 | 前后对比、优缺点 |
| flow | 连接节点 | 3-6步 | 流程、时间线、工作流 |
| mindmap | 中心辐射 | 4-8分支 | 概念图、头脑风暴、主题概览 |
| quadrant | 4区块网格 | 4个区块 | SWOT分析、优先级矩阵、分类 |

## 按位置推荐的布局

| 位置 | 推荐布局 | 原因 |
|----------|-------------------|-----|
| 封面 | sparse | 最大视觉冲击，清晰标题 |
| 铺垫 | balanced | 提供上下文但不过载 |
| 核心 | balanced/dense/list | 根据内容密度选择 |
| 收获 | balanced/list | 清晰的要点总结 |
| 结尾 | sparse | 干净的行动号召，令人难忘 |

## 网格单元

用于多元素构图：

| 名称 | 单元数 | 适用场景 |
|------|-------|----------|
| single | 1 | 主图，最大冲击力 |
| dual | 2 | 前后对比 |
| triptych | 3 | 步骤，流程 |
| quad | 4 | 产品展示 |
| six-grid | 6 | 清单，合集 |
| nine-grid | 9 | 多图画廊 |

## 视觉平衡

### Sparse 布局
- 单一焦点居中
- 四周充足呼吸空间
- 对称构图

### Balanced 布局
- 标题偏上
- 下方内容均匀分布
- 清晰的视觉层次

### Dense 布局
- 有序的网格结构
- 清晰的区块边界
- 紧凑但可读的间距

### List 布局
- 项目左对齐
- 清晰的数字/符号层次
- 一致的项目格式

### Comparison 布局
- 左右对称
- 清晰的视觉对比
- 区块间分隔线

### Flow 布局
- 方向流动（上→下或左→右）
- 箭头连接的节点
- 清晰的进度指示

### Mindmap 布局
- 中心主题节点
- 向外辐射分支
- 层级化子分支
- 有机弯曲连接线

### Quadrant 布局
- 4区块网格（2×2）
- 清晰的轴标签
- 每个象限内容独立
- 可选循环圆形变体
