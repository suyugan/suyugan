# 装饰素材

小红书信息图的视觉点缀和装饰元素。

## 强调标记

用于吸引注意力的特定内容元素。

| 名称 | 描述 | 适用场景 |
|------|-------------|----------|
| red-arrow | 指向目标的红色箭头 | 产品特点、重点 |
| circle-mark | 圆圈高亮批注 | 突出细节 |
| underline | 直线或波浪下划线 | 文字强调 |
| star-burst | 星爆炸效果 | 特价优惠、惊喜感 |
| checkmark | 勾号/对勾符号 | 已完成项目、优点 |
| cross-mark | 叉号符号 | 缺点、需避免的事 |
| exclamation | 感叹号装饰 | 重要警告 |
| question | 问号装饰 | FAQ、引发好奇 |
| numbering | 带圆圈的数字 | 步骤、排名 |
| bracket | 括号高亮 | 分组、强调 |

## 风格特定装饰

### Cute 风格
- 爱心、星星、闪光
- 丝带装饰、贴纸风格
- 可爱角色元素

### Notion 风格
- 简单线条涂鸦
- 几何形状、火柴人
- 最大留白、极简装饰

### Warm 风格
- 阳光、咖啡杯、温馨物品
- 温暖光效
- 友好、舒适的装饰

### Fresh 风格
- 植物叶子、云朵、水滴
- 简单几何形状
- 开放、透气的构图

### Bold 风格
- 感叹号、箭头
- 警告图标、强烈形状
- 高对比元素

### Pop 风格
- 粗体形状、对话气泡
- 漫画风效果、星爆
- 动感、有活力的装饰

### Retro 风格
- 网点、复古徽章
- 经典图标、胶带效果
- 做旧纹理叠加

### Chalkboard 风格
- 粉笔灰效果
- 手绘涂鸦
- 数学公式、简单图标
