# 图像处理层

应用于小红书信息图中图像元素的视觉效果。

## AI 抠图

用于产品/人物分离的主体提取风格。

| 名称 | 描述 | 适用场景 |
|------|-------------|----------|
| clean | 锐利边缘，精确边界 | 产品摄影、科技物品 |
| soft | 柔和过渡，羽化边缘 | 人像抠图、有机物体 |
| stylized | 手绘边缘处理 | 艺术构图 |

## 描边效果

抠图元素的边框处理。

| 名称 | 描述 | 适用场景 |
|------|-------------|----------|
| white-solid | 白色实线边框 | 经典贴纸感、高对比度 |
| colored-solid | 彩色实线边框 | 活泼氛围、品牌色 |
| dashed | 虚线/点线边框 | 手工美学、休闲感 |
| double | 双层描边 | 强调效果、高级感 |
| glow | 柔和外发光 | 梦幻、柔和美学 |
| shadow | 投影效果 | 增加深度、悬浮元素 |

**描边粗细指南**：
- 细：2-4px - 微妙、优雅
- 中：5-8px - 标准可见度
- 粗：10-15px - 强调效果

## 滤镜

小红书流行的色彩调整和氛围预设。

| 名称 | 中文 | 描述 | 氛围 |
|------|---------|-------------|------|
| clear-glow | 清透感 | 透亮、有光泽、发光 | 清新、年轻 |
| film-grain | 胶片感 | 复古胶片美学，颗粒质感 | 怀旧、艺术 |
| cream-skin | 奶油肌 | 柔滑、奶油色肤感 | 柔和、讨喜 |
| japanese-magazine | 日杂感 | 生活杂志美学 | 精致、向往 |
| high-saturation | 高饱和 | 鲜艳、有冲击力的色彩 | 活力、吸睛 |
| muted-tones | 莫兰迪 | 莫兰迪风格低饱和配色 | 高级、平静 |
| warm-tone | 暖色调 | 黄金时刻的温暖 | 温馨、舒适 |
| cool-tone | 冷色调 | 偏蓝冷调 | 现代、干净 |

## 纹理叠加

额外的质感效果。

| 名称 | 描述 | 适用场景 |
|------|-------------|----------|
| paper | 纸张或布料质感 | 手工感 |
| noise | 细腻颗粒噪点 | 胶片美学 |
| halftone | 网点图案 | 复古印刷风 |
| scratch | 轻微划痕 | 复古磨损感 |

## 混合模式

用于分层构图。

| 模式 | 效果 | 适用场景 |
|------|--------|----------|
| multiply | 变暗，融合 | 阴影效果 |
| screen | 变亮，发光 | 光效 |
| overlay | 增强对比 | 鲜艳构图 |
| soft-light | 柔和混合 | 自然分层 |

## 效果组合

不同风格的常见效果叠加：

### Cute 风格
- 滤镜：clear-glow 或 cream-skin
- 描边：white-solid（中等）
- 纹理：无

### Notion 风格
- 滤镜：无 或 muted-tones
- 描边：white-solid（细）或无
- 纹理：paper（微妙）

### Retro 风格
- 滤镜：film-grain
- 描边：double 或 dashed
- 纹理：halftone、scratch

### Bold 风格
- 滤镜：high-saturation
- 描边：colored-solid（粗）
- 纹理：无
