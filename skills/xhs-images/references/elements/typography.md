# 文字系统

小红书信息图的文字样式元素。

## 花字

用于强调和视觉吸引力的装饰文字处理。

| 名称 | 描述 | 适用场景 |
|------|-------------|----------|
| gradient | 渐变色填充 | 标题强调，现代感 |
| stroke-text | 描边空心字 | 封面标题，高可见度 |
| shadow-3d | 3D阴影/立体效果 | 关键词，增加深度 |
| highlight | 荧光笔标记效果 | 重点信息，关键要点 |
| neon | 霓虹发光效果 | 科技内容，夜间美学 |
| handwritten | 真实手写风格 | 个人触感，休闲 |
| bubble | 圆润膨胀字形 | 可爱，俏皮内容 |
| brush | 毛笔笔触质感 | 艺术感，动感 |

## 标签

结构化文字容器。

| 名称 | 描述 | 适用场景 |
|------|-------------|----------|
| black-white | 黑底白字 | 品牌名、价格、分类 |
| white-black | 白底黑字 | 简洁标签，极简风格 |
| bubble | 对话气泡风格 | 对话、批注、标注 |
| pointer | 带箭头指示的标签 | 产品标注，指向特点 |
| ribbon | 丝带/横幅形状 | 特别优惠，高亮 |
| stamp | 印章/徽章风格 | 真实感，推荐 |
| pill | 圆角胶囊形状 | 标签，分类，关键词 |

## 文字层级

推荐的文字尺寸层级。

| 层级 | 角色 | 相对大小 | 样式 |
|-------|------|---------------|-------|
| H1 | 主标题 | 100% | 粗体，装饰 |
| H2 | 区块标题 | 70-80% | 半粗 |
| H3 | 小节标题 | 50-60% | 中等粗细 |
| Body | 正文内容 | 40-50% | 常规 |
| Caption | 小字注释 | 30-35% | 细体 |

## 文字方向

| 方向 | 描述 | 适用场景 |
|-----------|-------------|----------|
| horizontal | 标准从左到右 | 大部分内容默认 |
| vertical | 从上到下竖排 | 杂志风格，传统中文 |
| curved | 沿曲线排列 | 装饰，环绕形状 |
| diagonal | 斜排文字 | 动感构图 |

## 文字效果

| 效果 | 描述 | 适用场景 |
|--------|-------------|----------|
| shadow | 文字投影 | 复杂背景上的可读性 |
| outline | 字形描边 | 高对比可见度 |
| glow | 文字柔光 | 梦幻，强调 |
| underline-wavy | 波浪下划线装饰 | 俏皮强调 |
| strikethrough | 删除线文字 | 前后对比，更正 |

## 语言注意事项

### 中文文字
- 标点符号：「」（）、。！？
- 字间距：字符间无空格
- 行高：1.5-1.8倍以提高可读性

### 混合文字
- 中文中的英文：保持基线一致
- 数字：使用一致的数字样式（等高或老式）

## 风格特定字体

### Cute 风格
- 圆润、气泡般的手写字
- 柔和阴影，俏皮装饰
- 粉色/马卡龙色点缀

### Notion 风格
- 干净的手绘字体
- 简洁的无衬线标签
- 极简装饰

### Bold 风格
- 有冲击力的手写字配阴影
- 高对比色彩
- 强描边

### Chalkboard 风格
- 所有文字带粉笔质感
- 可见的不完美感
- 多色粉笔变化
