# Bold 醒目风格

高冲击力、吸引注意力的美学。

## 元素组合

```yaml
canvas:
  ratio: portrait-3-4
  grid: single | dual

image_effects:
  cutout: clean
  stroke: colored-solid | double
  filter: high-saturation

typography:
  decorated: shadow-3d | stroke-text
  tags: black-white | ribbon
  direction: horizontal | diagonal

decorations:
  emphasis: exclamation | star-burst | red-arrow
  background: solid-saturated | gradient-linear
  doodles: arrows-curvy | squiggles
  frames: none
```

## 配色方案

| 角色 | 颜色 | 色值 |
|------|--------|-----|
| 主色 | 鲜红、橙、黄 | #E53E3E, #DD6B20, #F6E05E |
| 背景色 | 深黑、深灰 | #000000, #1A1A1A |
| 强调色 | 白、霓虹黄 | #FFFFFF, #F7FF00 |

## 视觉元素

- 感叹号、箭头、警告图标
- 强烈形状、高对比元素
- 戏剧性构图
- 粗犷几何形状

## 字体风格

- 有冲击力的手写字配阴影
- 高对比文字处理
- 大号、有气势的标题

## 最佳布局搭配

| 布局 | 兼容度 | 适用场景 |
|--------|---------------|----------|
| sparse | ✓✓ | 冲击力语句 |
| balanced | ✓ | 警告内容 |
| dense | ✓ | 关键信息卡片 |
| list | ✓✓ | 必知清单、排名 |
| comparison | ✓✓ | 戏剧性对比 |
| flow | ✓ | 关键流程步骤 |

## 最适合

- 重要提示和警告
- 必知内容
- 关键公告
- 排名和对比
- 吸睛钩子
