# Chalkboard 黑板风格

黑板背景配彩色粉笔绘制的美学。

## 元素组合

```yaml
canvas:
  ratio: portrait-3-4
  grid: single | dual | triptych

image_effects:
  cutout: stylized
  stroke: none
  filter: none

typography:
  decorated: handwritten
  tags: none
  direction: horizontal | vertical

decorations:
  emphasis: underline | circle-mark | arrows-curvy
  background: chalkboard
  doodles: hand-drawn-lines | stars-sparkles
  frames: none
```

## 配色方案

| 角色 | 颜色 | 色值 |
|------|--------|-----|
| 背景 | 黑板黑、墨绿黑 | #1A1A1A, #1C2B1C |
| 主要文字 | 粉笔白 | #F5F5F5 |
| 强调色 1 | 粉笔黄 | #FFE566 |
| 强调色 2 | 粉笔粉 | #FF9999 |
| 强调色 3 | 粉笔蓝 | #66B3FF |
| 强调色 4 | 粉笔绿 | #90EE90 |
| 强调色 5 | 粉笔橙 | #FFB366 |

## 视觉元素

- 手绘粉笔插图，带随意不完美的线条
- 文字和重点周围的粉笔灰效果
- 涂鸦：星星、箭头、下划线、圆圈、对勾
- 数学公式和简单图表
- 橡皮擦痕迹和粉笔残留质感
- 火柴人和简单图标
- 手绘感的连接线

## 字体风格

- 手绘粉笔字风格
- 所有文字都有可见的粉笔质感
- 不完美的基线增加真实感
- 用白色或亮色粉笔强调

## 风格规则

### 该做
- 所有元素保持真实的粉笔质感
- 全程保持不完美、手绘的质感
- 添加微妙的粉笔灰和涂抹效果
- 用多种颜色创建视觉层次
- 包含俏皮的涂鸦和批注

### 不该做
- 使用完美的几何形状
- 创建干净的数字线条
- 添加写实元素
- 使用渐变或光泽效果
