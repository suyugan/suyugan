# Minimal 极简风格

极致干净、高级感美学。

## 元素组合

```yaml
canvas:
  ratio: portrait-3-4
  grid: single

image_effects:
  cutout: clean
  stroke: none | white-solid
  filter: none | muted-tones

typography:
  decorated: none
  tags: white-black | pill
  direction: horizontal

decorations:
  emphasis: underline | circle-mark
  background: solid-white | solid-pastel
  doodles: hand-drawn-lines
  frames: none | rounded-rect
```

## 配色方案

| 角色 | 颜色 | 色值 |
|------|--------|-----|
| 主色 | 黑、白 | #000000, #FFFFFF |
| 背景色 | 米白、纯白 | #FAFAFA, #FFFFFF |
| 强调色 | 单一色（根据内容）| 蓝、绿或珊瑚 |

## 视觉元素

- 单一焦点、细线条
- 最大留白
- 简洁、干净的装饰
- 克制的视觉元素

## 字体风格

- 干净、简洁的手写字
- 极少粗细变化
- 优雅的字间距

## 最佳布局搭配

| 布局 | 兼容度 | 适用场景 |
|--------|---------------|----------|
| sparse | ✓✓ | 优雅语句 |
| balanced | ✓✓ | 专业内容 |
| dense | ✓✓ | 简洁知识卡片 |
| list | ✓ | 简单列表 |
| comparison | ✓ | 干净对比 |
| flow | ✓ | 优雅流程 |

## 最适合

- 专业内容
- 严肃话题
- 优雅呈现
- 高端产品
- 商务内容
