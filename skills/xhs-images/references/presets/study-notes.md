# Study Notes 学霸笔记风格

真实手写照片美学 - 学生笔记风格，密集但易读。

## 元素组合

```yaml
canvas:
  ratio: portrait-3-4
  grid: single

image_effects:
  cutout: none
  stroke: none
  filter: natural-photo

typography:
  decorated: none
  tags: none
  direction: horizontal

decorations:
  emphasis: circle-mark | underline | checkmark | cross | star-simple
  background: lined-paper-white
  doodles: arrows-simple | margin-notes | corrections | explanatory-diagrams
  frames: none
```

## 配色方案（三色批注系统）

| 角色 | 颜色 | 色值 |
|------|--------|-----|
| 主色 | 蓝色圆珠笔、黑色墨水 | #1E3A5F, #1A1A1A |
| 高亮 | 黄色荧光笔 | #FFFF00（50%透明度） |
| 强调 | 红笔（圈、下划线） | #CC0000 |
| 背景 | 白色横线纸 | #FFFFFF |

## 视觉元素

- 真实照片视角：书桌俯拍
- 手持蓝色圆珠笔，正在划线
- 极密集的手写内容，填满整页
- 红笔批注：圈、下划线、星号、方框
- 黄色荧光笔标记关键词
- 更正标记、边角挤入的小字
- 简单手绘符号：→ * ✓ ✗ !
- 不同笔压造成的深浅变化

## 字体风格

- 真实学生手写
- 潦草但易读，结构清晰
- 字号变化（大标题、正文、边角小注）
- 中日韩文字优化

## 内容结构

三区块布局：

### 顶部区块
- 核心主题（红笔多次圈起）
- 第一节标题 + 3-4个要点
- 箭头连接、红色下划线

### 中间区块
- 第二节标题（红笔方框）
- 编号步骤 ①②③
- 具体方法和补充说明

### 底部区块
- 第三节标题（红色星号）
- 时间节点 / 关键数据
- 金句引用 / 核心提示（角落小字）

## 最佳布局搭配

| 布局 | 兼容度 | 适用场景 |
|--------|---------------|----------|
| sparse | ✗ | 不适合 - 风格需要密集内容 |
| balanced | ✓ | 内容较少时 |
| dense | ✓✓ | 最佳 - 知识笔记、总结 |
| list | ✓✓ | 步骤清单、排名 |
| comparison | ✓ | 对比分析 |
| flow | ✓ | 流程图 |
| mindmap | ✓✓ | 思维导图笔记 |
| quadrant | ✓ | 象限分析 |

## 最适合

- 学习指南、考试笔记
- 知识整理、框架总结
- 教程总结、速记笔记
- "学霸笔记"风格内容
- 需要真实感的知识分享

## 风格规则

### 该做 ✓
- 保持内容极度密集
- 使用简单符号（→ * ✓ ✗ !）
- 用红笔批注重点
- 包含更正标记
- 边角挤入小字注释

### 不该做 ✗
- 使用复杂emoji
- 留太多空白
- 做整齐工整的排版
- 添加彩色装饰
- 包含卡通元素
