# 小红书大纲模板

带布局说明的信息图系列大纲生成模板。

## 文件命名

大纲文件使用策略标识命名：
- `outline-strategy-a.md` - 故事驱动型方案
- `outline-strategy-b.md` - 信息密集型方案
- `outline-strategy-c.md` - 视觉优先型方案
- `outline.md` - 最终选择的方案（从选中的方案复制）

## 图片文件命名

图片使用有意义的标识以便阅读：
```
NN-{type}-[slug].png
NN-{type}-[slug].md（在 prompts/ 目录）
```

| 类型 | 用途 |
|------|-------|
| `cover` | 第一张图（封面） |
| `content` | 中间内容图 |
| `ending` | 最后一张图 |

**示例**：
- `01-cover-ai-tools.png`
- `02-content-why-ai.png`
- `03-content-chatgpt.png`
- `04-content-midjourney.png`
- `05-content-notion-ai.png`
- `06-ending-summary.png`

**标识规则**：
- 从图片内容派生（kebab-case）
- 在系列中必须唯一
- 保持简短但有描述性（2-4个词）

## 布局选择指南

### 基于密度的布局

| 布局 | 适用场景 | 信息点 | 留白 |
|--------|-------------|-------------|------------|
| sparse | 封面、金句、冲击语句 | 1-2 | 60-70% |
| balanced | 标准内容、教程 | 3-4 | 40-50% |
| dense | 知识卡片、速查表 | 5-8 | 20-30% |

### 基于结构的布局

| 布局 | 适用场景 | 结构 |
|--------|-------------|-----------|
| list | 排名、清单、步骤 | 编号/项目符号垂直列表 |
| comparison | 前后对比、优缺点 | 左右分栏 |
| flow | 流程、时间线 | 箭头连接的节点 |

### 按位置推荐

| 位置 | 推荐布局 | 原因 |
|----------|-------------|-----------|
| 封面 | sparse | 最大冲击力、清晰标题 |
| 铺垫 | balanced | 有上下文但不过载 |
| 核心 | balanced/dense/list | 匹配内容密度 |
| 收获 | balanced/list | 清晰的要点总结 |
| 结尾 | sparse | 干净的行动号召、令人难忘 |

## 滑动钩子策略

每张图应以引导下一张的钩子结束：

| 策略 | 示例 |
|----------|---------|
| 预告 | "第一个就很强大👇" |
| 编号 | "接下来是第2个👇" |
| 最高级 | "下一个更厉害👇" |
| 提问 | "猜猜下一个是什么？👇" |
| 承诺 | "最后一个最实用👇" |
| 紧迫感 | "最重要的来了👇" |

## 策略差异化

三种策略应有明显差异：

| 策略 | 重点 | 结构 | 页数 |
|----------|-------|-----------|------------|
| A: 故事驱动型 | 情感化、个人化 | 钩子→痛点→发现→体验→总结 | 4-6 |
| B: 信息密集型 | 事实型、结构化 | 核心→信息卡片→对比→推荐 | 3-5 |
| C: 视觉优先型 | 氛围感、极简文字 | 主图→细节→生活场景→行动号召 | 3-4 |

**"AI工具推荐"示例**：
- `outline-strategy-a.md`: Warm + Balanced - 个人与AI的成长之旅
- `outline-strategy-b.md`: Notion + Dense - 知识卡片风格
- `outline-strategy-c.md`: Minimal + Sparse - 简约科技美学
