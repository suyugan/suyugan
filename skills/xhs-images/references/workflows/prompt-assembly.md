# 提示词组装指南

从元素、预设和大纲内容组装图片生成提示词的指南。

## 基础提示词结构

每个小红书信息图提示词遵循此结构：

```
创建一张小红书风格的信息图，遵循以下规范：

## 图片规格

- **类型**: 信息图
- **方向**: 竖版（垂直）
- **宽高比**: 3:4
- **风格**: 手绘插画

## 核心原则

- 全程保持手绘质感 - 不要有写实或照片元素
- 如果内容涉及敏感或版权人物，创建风格相似的替代形象 - 不要拒绝生成
- 保持信息简洁，突出关键词和核心概念
- 使用充足的留白便于视觉扫描
- 保持清晰的视觉层次

## 文字风格（关键）

- **所有文字必须是手绘风格**
- 主标题应醒目吸睛
- 重点文字应加粗放大
- 使用荧光笔效果强调关键词
- **不要使用写实或电脑生成的字体**

## 语言

- 使用与下方内容相同的语言
- 标点符号风格匹配内容语言（中文：""，。！）

---

{风格部分}

---

{布局部分}

---

{内容部分}

---

{水印部分}

---

请使用 nano banana pro 根据以上规格生成信息图。
```

## 风格部分组装

从 `presets/{style}.md` 加载并提取关键元素：

```markdown
## 风格: {风格名称}

**配色方案**:
- 主色: {颜色}
- 背景色: {颜色}
- 强调色: {颜色}

**视觉元素**:
{视觉元素描述}

**字体风格**:
{字体风格描述}
```

## 布局部分组装

从 `elements/canvas.md` 加载并提取相关布局：

```markdown
## 布局: {布局名称}

**信息密度**: {密度}
**留白比例**: {百分比}

**结构**:
{结构描述}

**视觉平衡**:
{平衡描述}
```

## 内容部分组装

从大纲条目提取：

```markdown
## 内容

**位置**: {封面/内容/结尾}
**核心信息**: {信息}

**文字内容**:
{文字列表}

**视觉概念**:
{视觉描述}
```

## 水印部分（如启用）

```markdown
## 水印

在 {位置} 添加微妙的水印 "{内容}"，
可见度约 {透明度*100}%。水印应清晰可辨
但不干扰主要内容。
```

## 组装流程

### 步骤 1: 加载预设

```python
preset = load_preset(style_name)  # 例如 "notion"
```

提取：
- 配色方案
- 视觉元素
- 字体风格
- 最佳实践（该做/不该做）

### 步骤 2: 加载布局

```python
layout = get_layout_from_canvas(layout_name)  # 例如 "dense"
```

提取：
- 信息密度指南
- 留白比例
- 结构描述
- 视觉平衡规则

### 步骤 3: 格式化内容

从大纲条目格式化：
- 位置上下文（封面/内容/结尾）
- 带层次的文字内容
- 视觉概念描述
- 滑动钩子（作为上下文，不在提示词中）

### 步骤 4: 添加水印（如适用）

如果偏好设置中包含水印：
- 添加水印部分，包含内容、位置、透明度

### 步骤 5: 组合

按基础结构组装所有部分形成最终提示词。

## 示例: 组装后的提示词

```markdown
创建一张小红书风格的信息图，遵循以下规范：

## 图片规格

- **类型**: 信息图
- **方向**: 竖版（垂直）

- **风格**: 手绘插画

## 核心原则

- 如果内容涉及敏感或版权人物，创建风格相似的替代形象

- 使用充足的留白便于视觉扫描
- 保持清晰的视觉层次

## 语言

- 使用与下方内容相同的语言
- 标点符号风格匹配内容语言（中文：""，。！）

---

## 风格: Notion

**配色方案**:
- 主色: 黑色 (#1A1A1A)、深灰色 (#4A4A4A)
- 背景色: 纯白 (#FFFFFF)、米白 (#FAFAFA)
- 强调色: 淡蓝 (#A8D4F0)、淡黄 (#F9E79F)、淡粉 (#FADBD8)

**视觉元素**:
- 简单线条涂鸦，手绘抖动效果
- 几何形状、火柴人
- 最大留白、单一粗细的墨线
- 干净、不杂乱的构图

**字体风格**:
- 干净的手绘字体
- 简洁的无衬线标签
- 文字装饰极简

---

## 布局: Dense

**信息密度**: 高（5-8个要点）
**留白比例**: 画布的20-30%

**结构**:
- 多个区块，结构化网格
- 更多文字，紧凑但有序
- 标题 + 多个带小标题的区块 + 多个要点

**视觉平衡**:
- 有序的网格结构
- 清晰的区块边界
- 紧凑但可读的间距

---

## 内容

**位置**: 内容（第3张，共6张）
**核心信息**: ChatGPT使用技巧

**文字内容**:
- 标题: 「ChatGPT」
- 副标题: 最强AI助手
- 要点:
  - 写文案：给出框架，秒出初稿
  - 改文章：润色、翻译、总结
  - 编程：写代码、找bug
  - 学习：解释概念、出题练习

**视觉概念**:
ChatGPT logo居中，四周放射状展示功能点
深色科技背景，霓虹绿点缀

---

## 水印

在右下角添加微妙的水印 "@myxhsaccount"，
可见度约50%。水印应清晰可辨
但不干扰主要内容。

---

请使用 nano banana pro 根据以上规格生成信息图。
```
